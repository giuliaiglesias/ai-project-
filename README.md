# AI in my everyday life

By Giulia Iglesias Broi. A personal student explainer about artificial intelligence, creativity, dependence, electricity demand and human supervision.

## Files and code

- `index.html` contains the writing, source links and AI acknowledgement.
- `styles.css` controls the layout, colours and mobile presentation.
- No JavaScript, build process or external images are needed.

The HTML uses meaningful sections and a navigation menu. CSS Grid puts the everyday examples into three columns on larger screens, and a media query stacks them on phones. Visible keyboard focus and a skip link support keyboard navigation.

## AI assistance

I wrote the initial ideas about saving time, creativity, dependence and developing our abilities. ChatGPT helped correct and expand the writing, link factual content to sources and generate the HTML and CSS. Source checks were supported by AI. The student author should review the sources, understand the code and test the final published page before submission.

## Update the existing website

Upload `index.html`, `styles.css` and `README.md` into the existing repository root, replacing the files with the same names. Commit the changes to `main`. GitHub Pages will redeploy automatically.
